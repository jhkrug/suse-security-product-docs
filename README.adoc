# SUSE Security product documentation.

SUSE Security product documentation is derived from upstream community
documentation at https://github.com/kubewarden/docs. Any changes to the
documentation should be made there with a small number of very limited
exceptions.

This repository is effectively a copy of the upstream repository with those
exceptions and the automated translated/localized content.

PRs for the localized content will not be accepted as they will be overwritten
by the automated translation process.

PRS that could be made against the upstream repository should be made there, and
will be rejected here. When made upstream the publishing process will
automatically update this repository with the changes.
